# Decision ledger

Settled decisions with rationale, date and who decided. Questions that are still open
live in [decisions](../../decisions/README.md); when one is resolved, add a row here (or
update the row it refines) and move its file to the [archive](../../archive/README.md).
Binding consequences also go in [`AGENTS.md`](../../../AGENTS.md).
